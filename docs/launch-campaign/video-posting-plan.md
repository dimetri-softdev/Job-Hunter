# JobHunter video posting plan

The six source videos are in `D:\JobHunter_Content`. Post them as separate native videos rather than combining all six into one long post. Keep the copy focused on what each clip shows; no tester or feedback ask is included.

## Recommended sequence

1. **Overview.mp4** — introduce JobHunter.
2. **Dashboard.mp4** — show the dashboard and first steps.
3. **Job Applications.mp4** — show application tracking.
4. **Roadmap.mp4** — show the roadmap workflow.
5. **Update Resume & Draft Cover Letter.mp4** — explain reviewable resume and cover-letter drafts.
6. **Overview_Tools.mp4** — use as a vertical status/story or a short tools highlight.

Space posts out over several days. Use the same video on LinkedIn and Facebook feeds; use the vertical video for WhatsApp Status. Add subtitles or platform captions so each post works without sound.

## File and publishing checks

- All six videos are about 28–30 seconds, H.264, 30 fps, with AAC stereo audio.
- Five videos are landscape (1920×1080); `Overview_Tools.mp4` is vertical (1080×1920).
- File sizes range from about 3.1 MB to 11.6 MB.
- The sampled frames show a visible “Made with Arcade” watermark. Keep it unless your Arcade export/license provides an approved watermark-free version; do not crop it out.
- A sampled frame contains the name “Maya Okafor,” and other screens include example job details. Confirm all names and data shown are fictional or approved for public posting.
- Preview the opening and ending of each clip, check that its audio is clear, and choose a clean cover frame before publishing.
- Avoid claiming that JobHunter submits applications automatically or guarantees job outcomes.
