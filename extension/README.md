# JobHunter Autofill Assistant

Build the Chrome/Edge Manifest V3 extension from the repository root:

```sh
npm run build:extension
```

In Chrome or Edge, open the extensions page, enable developer mode, choose **Load unpacked**, and select `extension/dist`. Sign in with your existing JobHunter Supabase account. The first sign-in asks for access to the Supabase project host; the extension needs that host only for authentication and token refresh.

The first time you use AI/autofill, choose **Yes, allow** or **No, thanks**. This consent is stored locally; use **Change consent** in the popup to change it later. If allowed, open a job application page and click the extension icon. **Scan and autofill this page** reads visible, empty controls on the active tab only, including custom Yes/No groups and custom/searchable dropdowns. Visible question labels and field metadata (names, placeholders, types, and options), the page title and website hostname, plus a limited non-sensitive career profile (work history, education, skills, and non-sensitive saved answers) are sent to the JobHunter backend and Google Gemini for draft suggestions. Current field values and contact details are not sent; sensitive saved answers, sensitive questions, and personal yes/no facts are excluded from AI. For open-ended questions about motivation or preferences, AI can generate an editable draft using the role/company context and profile where relevant; it must not invent personal history or claim experience the profile does not support. High-confidence, non-sensitive profile matches may be filled after your scan. AI-generated suggestions are always unchecked and require your review, even when the model reports high confidence. Sensitive and uncertain profile suggestions also stay unchecked in an extension-owned review tab. The AI request uses one **Application drafts** allowance and follows that feature's plan access and monthly limit. Filling changes field values only; the extension never submits the employer's form.

The tracker section is separate. Confirm the company, position, and source, then choose **Log application** to create a `SAVED` entry in your JobHunter tracker. The application page URL is included as the posting link. AI suggestions are generated server-side; provider credentials are never placed in the extension. The extension uses short-lived Supabase access tokens stored in extension-local storage and refreshes them through Supabase. It receives the public Supabase client configuration from `/api/v1/extension/config`; that endpoint exposes only the project's public anon key, never a service-role key. Deploy the backend config and AI endpoint before testing AI suggestions.
